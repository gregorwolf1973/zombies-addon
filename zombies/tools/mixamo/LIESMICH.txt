Mixamo-FBX -> Draufsicht-Laufschleifen (Prototyp, nur exakt senkrechte Draufsicht). FBX liegen in fbx/ (gitignored, nie committen/hochladen).
0. lib/ (gitignored): three.module.js + examples/jsm/{loaders/FBXLoader.js,libs/fflate.module.js,curves/NURBSCurve.js,curves/NURBSUtils.js} aus three@0.160.0 (cdn.jsdelivr.net/npm/three@0.160.0/...)
1. python3 -m http.server 8818 --bind 127.0.0.1   (hier)
2. google-chrome --headless=new --enable-unsafe-swiftshader --use-angle=swiftshader --remote-debugging-port=9333 --user-data-dir=<scratch> about:blank
3. EXTRA="&gross=2.5" PYTHONPATH=<pil> sh pruefe.sh <ordner>     -> walk/run/running_streifen.png (16 Bilder à 160 px, 4 m je Bild)
   (Einzeln: node cdp.mjs 'http://127.0.0.1:8818/seite.html?datei=Zombie%20Walk.fbx&nur=info' x.txt = Maße)
4. Altes Sprite zombie_hemd als alt0..5.png (160er Felder 18..23 aus client/grafik/figuren.png) in den Ordner legen, dann
   PYTHONPATH=<pil> python3 anschauen.py <ordner>  -> mixamo_proto.gif, _phasen.png, _kreis.gif
Chrome und Server danach per PID beenden.
5. Atlas fürs Spiel: sh alle.sh <ordner> (alle Figuren x Clips), dann PYTHONPATH=<pil> python3 atlas_bauen.py <ordner> ../../client/grafik
   -> client/grafik/zombies_<figur>.webp (3200x1200, Stil C: Gamma 0,72, ohne Kontur) + zombies_neu.json; Logik client/zombiefiguren.mjs, Einbau client/spiel.mjs (Backend-Schalter zombieFigurenNeu, state.optionen Bit 256).
Helden (Prototyp): helden_jobs.json (Auftragsliste, Waffenwerte) + held.html (rendert eine Figur: fig=jennifer|swatguy, optional nur=<Aufträge>, ansicht=seite zum Prüfen der Waffenlage)
   + lib/examples/jsm/{loaders/GLTFLoader.js,utils/BufferGeometryUtils.js} (three@0.160.0). Waffen siehe WAFFEN_QUELLEN.txt (fbx/waffen/*.glb). Pakete vorher in fbx/<fig>/{pistole,gewehr}_pak entpacken.
   Ablauf: CDP_PORT=9444 WARTE=900 node cdp.mjs 'http://127.0.0.1:8828/held.html?fig=jennifer' o/jennifer.txt ; python3 held_streifen.py o/jennifer.txt o jennifer 192 ;
           python3 held_proto.py <o> <zombie-streifen> helden_proto.html   (Farbstil C, Szene mit Zombies)
   Jennifers stehen.fbx ist laut Dauer ein Lauf-Clip: held.html nimmt dafür den Leerlauf von swatguy (Präfix mixamorig1 -> mixamorig wird umbenannt).
6. Helden fürs Spiel: Streifen je Figur wie oben (held_streifen.py <o> <ordner> <fig> 160 0, je fig=jennifer|swatguy), dann
   PYTHONPATH=<pil> python3 helden_atlas_bauen.py <ordner> ../../client/grafik -> helden_held.webp / helden_heldin.webp (2560x4040) + helden_neu.json (Clips, Weg je Zyklus, Mündung je Schussbild).
   Waffenlängen in helden_jobs.json = echte Länge (Render doppelt so groß); Logik client/heldenfiguren.mjs, Einbau client/spiel.mjs (figurDarstellen, schuss), Schalter heldenFigurenNeu (Bit 512).
